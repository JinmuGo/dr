EnterTrace a line

See who wrote each line.

git blame names you because you committed. dr names the agent session and the request you gave it.

aAsk why

Ask the author.

Ask the session that wrote a line why it wrote it that way. dr asks a fork. Your original conversation stays as it was.

cLeave a comment

Get fixes from the author.

Leave comments and :submit. Each session fixes only its own lines. y applies a fix. x drops it.

Three agents, one diff.

Claude Code, Codex and OMP sit side by side. Each session has its own color.

Local and exact.

Origins come from local session logs with no model calls. Unexplained lines stay unknown. No server, account or telemetry.
