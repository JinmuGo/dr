Diff review with the AI that wrote it.

dr shows which agent session wrote each changed line and what you asked it. Ask that session why, leave review comments, and get fixes back from it. For Claude Code, Codex and OMP, in your terminal.

$curl -fsSL https://dr.jinmugo.com/install.sh | sh
$brew install jinmugo/tap/dr
$nix profile install github:JinmuGo/dr
$go install github.com/JinmuGo/dr@latest

@@ why dr @@

  1. 1+

    See who wrote each line. git blame names you, because you committed. dr names the agent session that wrote the line and the request you gave it.

    claude c1a0 #2
  2. 2+

    Ask the author. Press a on a line to ask the session that wrote it why. dr asks a fork, so your conversation stays as it was.

    a ask
  3. 3+

    Get fixes from the author. Leave comments as in a pull request review, then :submit. Each session fixes only the lines it wrote; y applies a fix and x drops it.

    c comment → y apply
  4. 4+

    Three agents, one diff. Each session gets its own color, so lines from Claude Code, Codex and OMP sit side by side in one review.

    three sessions
  5. 5+

    Local and exact. Origins come from the session logs on your machine, with no model calls. Lines dr cannot explain stay unknown. No server, no account, no telemetry.

    ┆ unknown

Install

Script

$curl -fsSL https://dr.jinmugo.com/install.sh | sh

macOS and Linux. Downloads the latest release, checks its checksum and puts dr in ~/.local/bin. Pick a release or a directory with sh -s -- --version 0.1.0 --dir /usr/local/bin.

Homebrew

$brew install jinmugo/tap/dr

macOS and Linux. brew upgrade keeps it current.

Nix

$nix profile install github:JinmuGo/dr

Or try it once with nix run github:JinmuGo/dr. The flake builds from source.

Go

$go install github.com/JinmuGo/dr@latest

Go 1.26 or later.

dr needs git. Asking and fixing run the CLI of the agent that wrote the lines: claude, codex or omp. More in the install guide.
